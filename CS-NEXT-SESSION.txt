MEASUREMENT TRAPS THIS SESSION MEASURED - THEY WILL BITE AGAIN:
- A pytest traceback renders a subprocess.run(env=...) frame's WHOLE
  environment dict. That is how an sk-ant- admin key reached a suite
  log on 2026-09-19. It is redacted now, but the RENDERING behaviour is
  unchanged - assume any frame argument is published.
- pytest TRUNCATES a long dict repr. A variable added LAST falls
  outside the shown portion, so an arm planting there measures nothing
  and passes. Bind the value to a frame local and run --showlocals, or
  put it in the exception message.
- A child pytest whose rootdir sits deep under the home directory
  renders stdlib frames as RELATIVE paths, so NO absolute home path is
  emitted. An arm using the home placeholder as a control is then
  measuring how deep a temp directory happens to be, not whether
  redaction ran. Measured green from a plain parent and red from a
  pytest parent, same command.
- pytest_collectreport written as hookimpl(wrapper=True) raises
  INTERNALERROR. That hook is HANDED a report rather than building one,
  so the yield gives the hook's combined result - a list. Use tryfirst
  and mutate in place. pytest_runtest_makereport is the wrapper.
- A CONTROL THAT NAMES A PLATFORM-SPECIFIC VALUE GRADES THE PLATFORM.
  A CS-1156 arm asserted ALLUSERSPROFILE appeared in a child report, to

  run here was green at 9143 passed and tier 1 went red on ubuntu on
  three arms, for a reason with nothing to do with the mechanism. The
  marker is the name of a FRAME LOCAL now - the channel the secret
  actually travels through. Before writing any control, ask which
  platform its value exists on.
